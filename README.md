# COSC 311 Threaded BST

A Java console project that uses threaded binary search trees to index student
records. Run it from the program directory, which contains dataset.txt:

    cd "COSC311 - Program 3 - Adam Pollack"
    mkdir build
    javac -d build -sourcepath src src/COSC311_Driver.java
    java -cp build COSC311_Driver

Choose a numbered menu option to work with records. Use numeric IDs. Enter 0
to exit.
